# Analisis Kebutuhan Sistem

## 2.2.1 Kebutuhan Perangkat Keras (Hardware)
Perangkat keras yang digunakan untuk menjalankan aplikasi pencatatan peminjaman sarpras ini secara optimal, baik pada tahap pengembangan maupun pengujian (deployment lokal), meliputi:
- **Processor:** Intel Core i3 atau setara (minimal dual-core 2.0 GHz).
- **RAM:** Minimal 4 GB (disarankan 8 GB).
- **Hard Disk / Storage:** Tersedia ruang kosong minimal 500 MB untuk instalasi web server, database, dan file proyek.
- **Display:** Resolusi layar minimal 1366x768 piksel untuk kenyamanan antarmuka AdminLTE.

## 2.2.2 Kebutuhan Perangkat Lunak (Software)
Perangkat lunak yang dibutuhkan untuk menjalankan sistem secara offline (tanpa internet) mencakup:
- **Sistem Operasi:** Windows 10/11, Linux, atau macOS.
- **Web Server & Database:** Laragon / XAMPP (PHP 8.2+, MySQL / MariaDB).
- **Framework & Bahasa:** Laravel 13, Composer, Node.js (opsional untuk asset compiling).
- **Browser:** Google Chrome, Mozilla Firefox, atau Microsoft Edge versi terbaru untuk mengakses antarmuka berbasis web.
