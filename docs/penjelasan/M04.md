# Penjelasan Milestone M04 — Riwayat & Export

## Apa yang dibuat
- `app/Services/RiwayatService.php`: Service class yang memanggil stored procedure `sp_riwayat_peminjaman`.
- `app/Exports/RiwayatExport.php`: Class export Maatwebsite Excel untuk format Excel (.xlsx) dan CSV.
- `app/Http/Controllers/RiwayatController.php`: Controller untuk menampilkan pratinjau riwayat peminjaman dengan filter dan proses unduh file export.
- `routes/web.php`: Pendaftaran rute `/riwayat` dan `/riwayat/export`.
- `resources/views/riwayat/index.blade.php`: Halaman antarmuka Riwayat Peminjaman lengkap dengan tombol cepat rentang tanggal, filter status/kategori, pencarian peminjam, pratinjau tabel, dan tombol unduh CSV/Excel.

## Kenapa dibuat begini
- Menggunakan stored procedure `sp_riwayat_peminjaman` secara langsung agar logika filter rentang tanggal, status, dan pencarian diproses secara konsisten di database.
- Menggunakan paket `maatwebsite/excel` v4.0 untuk mendukung export file CSV dan .xlsx dengan PHP 8.5.

## Alur kode
1. Pengguna membuka menu Riwayat & Export -> `RiwayatController@index` menerima parameter filter (dari, sampai, status, peminjam, id_kategori) -> memanggil `RiwayatService` yang mengeksekusi `sp_riwayat_peminjaman` -> merender `riwayat.index`.
2. Pengguna menekan tombol Export CSV atau Export Excel -> `RiwayatController@export` memanggil `RiwayatExport` dengan hasil query stored procedure -> Maatwebsite Excel mengunduh file sesuai format yang dipilih.

## Cara menguji
| No | Langkah | Hasil yang diharapkan |
|---|---|---|
| 1 | Buka menu Riwayat & Export | Tampil filter rentang tanggal dan tabel pratinjau. |
| 2 | Gunakan tombol cepat rentang waktu (misal: 30 Hari / Bulan Ini) | Filter tanggal otomatis terisi dan pratinjau memperbarui data. |
| 3 | Klik tombol Export CSV atau Export Excel | Berkas terunduh otomatis dengan nama sesuai filter aktif. |

## Pertanyaan yang mungkin muncul saat ujian
- **Q:** Mengapa data riwayat pratinjau dan hasil export selalu identik?
  **A:** Karena keduanya bersumber dari fungsi pemanggilan stored procedure `sp_riwayat_peminjaman` yang sama persis.

## Contoh modifikasi yang mungkin diminta
- **Modifikasi:** Menambah kolom baru pada hasil export riwayat.
- **File yang diubah:** `app/Exports/RiwayatExport.php`.
